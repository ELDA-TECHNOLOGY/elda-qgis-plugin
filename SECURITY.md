# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Use GitHub's private reporting instead: on this repository, open the **Security** tab and click **Report a vulnerability**. The report is visible only to the maintainers.

Tell us what you found, how to reproduce it, and which version of the plugin and of QGIS you used. We aim to answer within five working days.

## Scope

This repository holds the QGIS plugin only. The plugin contains no secret and grants no right an ELDA account does not already have: access control is enforced by the ELDA platform.

A problem in the ELDA platform itself can be reported the same way.

## Supported versions

Only the latest release receives fixes.
